# VyOS コンテナ（veth 上）では commit できず、CI で検証できない設定の一覧。
# 書式: <cmds ファイル> | <コマンド（ファイルの行そのまま）> | <理由>
#
# scripts/vyos-check-cmds.sh は、ここに載った行だけを除いて残りを commit し、
# さらに載った行を 1 本ずつ足して commit が「失敗すること」を確かめる。
# 載せた行が実は通る、または載っていない行が落ちる、のどちらでも CI を落とす。
# 実機（PC02）では全行を投入する。

# ① リングバッファ: veth のドライバはリングバッファの変更に対応していない。
#    commit 時に「Driver does not support RX ring-buffer configuration!」で落ちる（tx の行でも同じ文言）。
#    同じファイルの offload gro / gso / sg / tso は veth でも commit できる（性能上の意味は実機でしか測れない）
tuning-1-offload.cmds | set interfaces ethernet eth1 ring-buffer rx '4096' | veth のドライバはリングバッファの変更に非対応（commit で Driver does not support RX ring-buffer configuration!）
tuning-1-offload.cmds | set interfaces ethernet eth1 ring-buffer tx '4096' | veth のドライバはリングバッファの変更に非対応（commit で Driver does not support RX ring-buffer configuration!）
tuning-1-offload.cmds | set interfaces ethernet eth2 ring-buffer rx '4096' | veth のドライバはリングバッファの変更に非対応（commit で Driver does not support RX ring-buffer configuration!）
tuning-1-offload.cmds | set interfaces ethernet eth2 ring-buffer tx '4096' | veth のドライバはリングバッファの変更に非対応（commit で Driver does not support RX ring-buffer configuration!）

# ④ 性能プロファイル: vyos-build の scripts/iso-to-oci がコンテナ用イメージから
#    system option performance の定義（templates/system/option/performance）を削除しているため、set の段階で拒否される
tuning-4-performance.cmds | set system option performance 'network-throughput' | コンテナ用イメージでは system option performance の定義が削除されている（iso-to-oci）。set で Configuration path is not valid

# §6-6 実機の管理系（mgmt-home.cmds）: 以前は CI のコンテナに VRF デバイスを作る権限が無く、set vrf name MGMT が
#    「ip link add dev MGMT ... PermissionError」で落ち、VRF を参照する 4 行も「VRF "MGMT" does not exist!」で落ちていた。
#    2026-10-29 の GitHub のランナーでは VRF を作れて、5 行とも commit が通る（PR #10 の CI で確認）ので、一覧から外した。
#    実機（PC02）では 2026-10-25 に commit が通ることを確認済み（configs/pc02/baseline.cmds）

# SNMP（snmp-mgmt.cmds）の VRF: 差分は基準（フェーズ1）に 1 本ずつ入れて検査するので、VRF MGMT を作る mgmt-home.cmds が
#    入っておらず「VRF "MGMT" does not exist!」で落ちる（実機では mgmt-home.cmds で作ってある）。community と network の行はコンテナで commit する
#    （community は置き換え用の印 @SNMP_COMMUNITY@ のまま。@ は community の名前に使える文字）
snmp-mgmt.cmds | set service snmp vrf 'MGMT' | この差分だけでは VRF MGMT が無いので「VRF "MGMT" does not exist!」
